# Лабораторная работа № 3 — Асинхронный JavaScript и REST API

Приложение «Доска публикаций» (JSONPlaceholder).

## Запуск
Откройте `index.html` в браузере (двойной щелчок). Нужен доступ в интернет. Сервер и установка не нужны.

## Реализовано
- Кнопка «Загрузить публикации»: GET `https://jsonplaceholder.typicode.com/posts?_limit=5` через `fetch` и `async/await`, проверка `response.ok`, вывод 5 публикаций (заголовок и текст) через DOM (`textContent`).
- Форма «Заголовок» / «Текст»: валидация после `trim()`, `preventDefault`, POST `{title, body, userId: 1}` в JSON с `Content-Type: application/json`, проверка `response.ok`, вывод заголовка и ID из ответа в карточке под формой, сообщение об успехе с HTTP-кодом.
- Сообщения «Загрузка…» / «Отправка…»; ошибки сети и HTTP (например, 404) обрабатываются через `try/catch/finally`, кнопки снова активны для повторной попытки.

## Результаты проверки
- Загрузка публикаций → отображаются 5 записей с заголовками и текстом.
- Пустые поля и одни пробелы → сообщение об ошибке, запрос не отправляется.
- Корректные данные → ответ HTTP 201, на странице появляются заголовок и ID.
- Адрес GET временно заменён на `/postz` → 404, понятное сообщение, кнопка снова доступна; после проверки адрес восстановлен.
